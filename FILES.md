# File Guide — Mahesh Pav Bhaji Website

Every file in this project and what it is for. Written for whoever picks this
up next, whether that is you, another developer, or an agency.

---

## Getting it running

```bash
npm install     # restores node_modules (not shipped — see "What is not in this archive")
npm run dev     # development server on http://localhost:3000
npm run build   # production build
npm run start   # serve the production build
npm run lint    # ESLint
npx tsc --noEmit  # type check
```

Requires Node.js 20 or newer.

## Where to change common things

| I want to change… | Edit this |
|---|---|
| An outlet's name, phone, or address | `src/data/outlets.ts` |
| Rating, review count, hours, cuisines | `src/data/business.ts` |
| A dish name or menu category | `src/data/menu.ts` |
| Wording of a WhatsApp message | `src/lib/outlet-enquiry.ts` |
| Which enquiry options appear as chips | `src/lib/outlet-enquiry.ts` |
| Brand colours, fonts, spacing scale | `tailwind.config.ts` |
| The deployed web address | `NEXT_PUBLIC_SITE_URL` env var (see `src/lib/site.ts`) |
| Security headers / caching | `next.config.mjs` |
| Page title, description, social card text | `src/app/layout.tsx` |

**Enabling "find my nearest outlet":** it is built and dormant. Fill in the
`coordinates` for each outlet in `src/data/outlets.ts` (currently `null`
because they were never verified) and the feature switches itself on. Nothing
else needs changing.

| `.gitignore` | What version control ignores. |
| `.mcp.json` | Editor tooling config. Not used by the site at runtime. |
| `next-env.d.ts` | Auto-generated by Next.js. Do not edit. |

| File | Purpose |
|---|---|
| `outlets.ts` | The seven outlets. Names, subtitles, phones, addresses. WhatsApp numbers, `tel:` links, map URLs and postal addresses are all **derived** from the phone/address so they can never drift apart. |

## What is not in this archive, and why

**`node_modules/` (658 MB)** — third-party packages. Deliberately excluded:
it is large, and it contains compiled binaries built for this Linux machine
(`sharp`, the SWC compiler) that would not run on Windows or macOS. Shipping
it would be actively harmful. `npm install` rebuilds it correctly for your
machine, at the exact versions recorded in `package-lock.json`.

**`.next/` (154 MB)** — the compiled output of `npm run build`. Regenerated
every build; nothing is lost by excluding it.

Everything else is present, including the `.git` folder with the project's
full commit history.

## Notes worth knowing

- **Hosting.** The security headers in `next.config.mjs` need a host that
  applies them. Netlify's Next.js runtime does. A plain static export would
  need them redeclared in a `_headers` file.
- **Outlet map links** are Google Maps *searches* built from each outlet's
  address, not confirmed place pins — no per-outlet place URLs were supplied.
  Replacing them with verified links is a one-line change per outlet in
  `src/data/outlets.ts`.
- **The rating and opening hours** were verified for the Katargam listing
  only. The site and the structured data both say so rather than implying
  they apply to all seven outlets.
- **Known accessibility issue.** The hero's saffron accent line (`#F2A93B` on
  white) has a contrast ratio of 2.0:1, below the 3:1 WCAG AA minimum for
  large text. It was left as-is because the brand colour was fixed.
  Darkening it to about `#B87A0E` reaches 3.6:1 and looks very similar.
